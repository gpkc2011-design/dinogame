# Dino Dash

An endless-runner browser game: an orange dinosaur jumps green cacti and ducks under birds.

## Play
- **Space / ↑ / tap** – jump
- **↓** – duck (or drop faster mid-air)

## Deploy on Vercel
1. In Vercel, click **Add New → Project** and import this repo.
2. Framework preset: **Other**. Leave the build command and output directory empty.
3. Click **Deploy**.

It's a single static `index.html` with no build step or dependencies.
